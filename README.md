# Orithar · downloads

Prévia Técnica do **Orithar**, RPG de ação voxel. Este repositório guarda apenas os instaladores; o código do jogo não fica aqui.

- **Windows 10/11 (64 bits):** [Orithar-Setup.exe](https://github.com/victorhaus/orithar-releases/releases/latest/download/Orithar-Setup.exe). Rode e siga o assistente. Se o Windows avisar, clique em *Mais informações* › *Executar assim mesmo*. O jogo se atualiza sozinho.
- **Mac (Apple Silicon e Intel):** [Orithar-Mac.dmg](https://github.com/victorhaus/orithar-releases/releases/latest/download/Orithar-Mac.dmg). Arraste para Aplicativos. Na primeira vez: Ajustes do Sistema › Privacidade e Segurança › *Abrir Mesmo Assim*.

Todas as versões: [Releases](https://github.com/victorhaus/orithar-releases/releases).
